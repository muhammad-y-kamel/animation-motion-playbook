## Prevention for every animation/motion project
Read playbook before script, layout, rig, motion, sound, render and archive. Log every observed error including agent/reviewer-discovered errors without user intervention; record cause, all attempted repairs, rejected/uncertain outcomes, best tested solution, exact identities, regression and limitations. New source or mux invalidates affected evidence. Never label an inferred/proposed fix proven. User rejection reopens creative gate regardless of numerical passes. Maintain distinct story comprehension, visible acting/contact, semantic audio, encoded QA, archive and publication gates.
