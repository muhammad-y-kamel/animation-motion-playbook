# MOKI-EP030-006 — Declared grip anchors did not correspond to a drawn control rope

- Project: MOKI & PEB / EP030
- Discovered by: producer; independent reviewer attribution retained where stated.
- Status: repaired at source; final encoded validation pending.

## Symptom and cause
Haul/catch hands at x350/y760 or805 held empty air when the only tether ended near y880. The balance brake also targeted an implicit point, not the displayed cord.

## Preserved attempts and best tested repair
Preserved art-v6 and story-v6. Added a separate visible auxiliary return rope and wheel, connected to the winch; aligned the balance grip with the displayed control knob. REVIEW-002 then found fist/deck interference and moved only the auxiliary input rope/grips to x320, retaining the main pulley loop and the ground cleat at x350. All actual attempts remain in rejected snapshots.

## Prevention and regression
Validate grips against rendered object geometry, not self-declared matching anchors alone. Include the full hand envelope and nearby moving structures in a swept clearance check.
