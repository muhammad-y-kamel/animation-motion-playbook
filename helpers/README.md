# Sampled contact regression helpers

`contact-utils.cjs` contains no episode dimensions. Supply each project’s explicit support/obstacle registry and actual rendered geometry. The EP030 adapter and test reports are in `../evidence/EP030/qa/`.

The helpers sample time and stroked-ellipse boundaries; they are not analytic continuous collision detection or arbitrary-mesh proof. Use absolute support residuals, explicit airborne/carried states and fixed machinery/architecture exclusion. Run full-resolution and encoded review separately. See the [recurrence analysis](../evidence/EP030/qa/CONTACT-REGRESSION-RECURRENCE.md).
